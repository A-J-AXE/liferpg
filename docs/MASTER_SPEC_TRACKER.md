# LifeOS specification tracker
The existing [implementation checklist](../CHECKLIST.md) remains the feature baseline. This supplement tracks the RPG home.

- Overview uses the shared character, skill, habit, and reward records.
- Completed tasks leave active views and remain reopenable in Completed tasks.
- Goals, Skills, Marketplace, Coin vault, Focus, Journal, Growth, Battle and openGym use functional destinations.
- Social and a dedicated recovery workspace have no corresponding module. Focus gives access to the existing focus and break timer.
- Reward receipts created before timestamps were recorded show no invented timestamp.
